# Governance

GoVibe is an independent open-source project. No organization, company, or permanent maintainer group is asserted by this repository. Repository ownership and merge authority belong to the GitHub account that publishes and maintains the project; that account should identify active maintainers in the repository settings before soliciting contributions.

For now, changes are proposed through issues and pull requests. A maintainer reviews correctness, tests, security, privacy, accessibility, compatibility, and documentation, and records material decisions in a short architecture note when they affect the project direction. Contributors do not gain merge or release authority merely by submitting work.

A release requires an explicit maintainer decision after CI passes and known limitations are disclosed. The manual CI artifact workflow does not create releases. If the project adopts a formal organization or voting process, this document should be updated transparently rather than implying one already exists.

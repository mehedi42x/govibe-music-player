# Support

For usage questions and reproducible bugs, open a GitHub issue using the appropriate template after the repository owner publishes the reviewed changes. Include Android OS version and reproduction steps, but do not attach private audio, authentication tokens, or personal listening data.

Current known limitations: Android codec support varies by device; there is no library backup/export, streaming service, or executable third-party plugin runtime. The app uses Media3 for playback and provides system media controls. Audio output characteristics are not measured. Android SDK/NDK build and device verification remain pending in the current local review tree.

For security-sensitive reports, use the private reporting route described in `SECURITY.md`; do not open a public issue with exploit details.

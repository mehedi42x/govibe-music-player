# Support

For usage questions and reproducible bugs, open a GitHub issue using the appropriate template after the repository is public. Include browser/OS version and reproduction steps, but do not attach private audio, authentication tokens, or personal listening data.

Current known limitations: supported codecs and PWA installation vary by browser; browser storage can be quota-limited or cleared; there is no library backup/export, streaming service, native mobile app, lock-screen integration, or third-party plugin runtime. Audio output characteristics are not measured.

For security-sensitive reports, use the private reporting route described in `SECURITY.md`; do not open a public issue with exploit details.
